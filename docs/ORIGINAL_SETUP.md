# Equity Lens 수집기

영상에서 본 에이전트 콘솔처럼 사이트에서 결과를 읽고 분석을 요청하는 연결 패키지입니다.
계좌 조회·자료 수집·세 에이전트 모델 호출은 이 컴퓨터/서버에서 실행됩니다.
사이트를 게시했다고 이 프로그램이 24시간 실행되는 것은 아닙니다.

## 지금 가능한 사용: 결과 파일 가져오기

1. macOS 또는 Linux에서 Python 3.11 이상을 사용합니다.
2. 아래 명령으로 별도의 환경을 만듭니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py demo
```

`demo-output/latest_portfolio.json`과 `demo-output/reports/DEMO_*.json`을
사이트 → 데이터 연결 → 결과 파일 가져오기에서 선택합니다.
이 파일은 가상 데이터입니다. 실제 포트폴리오용으로 사용하지 마세요.
키 설정 후 `python app.py live`가 생성하는 `data/latest_portfolio.json`과
`data/reports/`의 최신 JSON을 가져오면 실제 수집 결과를 확인할 수 있습니다.

## 자동 연결

사이트가 본인 전용이면 외부 프로그램의 요청을 호스팅 접근 설정에서 차단합니다.
현재 최초 배포는 본인 전용입니다. 자동 연결 전에 사이트 접근 설정을 조정해야 합니다.
사이트를 공개하더라도 `/dashboard`, `/connect`, `/api/workspace`는 로그인이 필요하고
사용자별로 자신의 레코드만 조회합니다. 공개 시연에는 가상 데이터만 포함합니다.
`/api/ingest`는 해당 사용자에게 발급된 별도의 연결 토큰으로 보호합니다.

1. 토스 Open API에서 조회 권한과 실행 컴퓨터/서버의 허용 IP를 등록합니다.
2. 아래 명령으로 예시 설정을 복사합니다.

```bash
cp env.example .env
chmod 600 .env
```

3. `.env`에 토스 클라이언트 ID/비밀키를 입력합니다. 복수 계좌이면 정확한 TOSS_ACCOUNT_SEQ를 지정합니다.
4. 기본 모델은 로컬 Ollama입니다. 실제 설치한 JSON 출력 지원 모델 이름을 LLM_MODEL에 입력합니다.
   Qwen3는 기본 thinking이 오래 걸릴 수 있어 이 패키지는 `OLLAMA_THINK=false`를 기본으로 사용합니다.
   로컬 모델 한 개에 두 요청을 동시에 보내면 메모리 경쟁이 생기므로 에이전트 1과 2는 순서대로 실행합니다.
   입력은 계속 분리되며, 이후 에이전트 3이 두 결과를 종합합니다.
5. 사이트 → 데이터 연결에서 토큰을 발급하고 EQUITY_LENS_TOKEN에 입력합니다.
6. EQUITY_LENS_URL에는 주소창의 HTTPS 기본 주소를 입력합니다. `/connect` 같은 경로를 붙이지 않습니다.
7. 실행합니다.

```bash
python site_worker.py
```

`app.py live --watch`와 `site_worker.py`를 동시에 실행하지 마세요.
동일 프로젝트는 잠금으로 중복 실행을 막습니다. 서로 다른 폴더나 서버에서도 같은 토스 키를 동시에 사용하지 마세요.
토스의 새 토큰 발급이 기존 토큰을 무효화할 수 있습니다.

## 동작 주기

- 토스 시세: WebSocket 체결 이벤트 수신. 종목별 시세 발생 시각을 보존합니다.
- 보유 종목·수량·환율: 기본 60초. 실행 중 네트워크 대기 시간은 추가될 수 있습니다.
- 사이트 전송: 기본 약 10초. 사이트는 10초마다 조회하므로 체결가 표시에는 추가 지연이 있습니다.
- 자동 뉴스 수집·세 에이전트 분석: 기본 1시간. config.json에서 변경합니다.
- 사이트 ANALYZE: 온라인 수집기에 작업을 요청합니다. 진행 중 중복 요청과 5분 이내 반복 요청은 제한합니다.
- 1번과 2번은 서로의 입력이나 출력을 공유하지 않고, 3번은 두 결과를 받아 실행합니다.
- 로컬 Ollama 기본 빠른 모드에서는 1번과 2번을 순차 실행합니다. 두 에이전트의 입력 독립성은 유지됩니다.
- 충분한 메모리와 Ollama 병렬 처리 설정이 있으면 `OLLAMA_PARALLEL_AGENTS=true`로 바꿀 수 있습니다.
- 전송 실패 시 이전 데이터와 원래 기준 시각을 유지합니다. 30분이 넘은 작업은 다음 수집기 요청 시 실패로 만료됩니다.

## 데이터와 비용

사이트 연결 시 종목·수량·가격·원화 평가액·분석 보고서가 사용자별 서버 저장소에 전송됩니다.
토스 키, 계좌번호, 평균 매입가는 사이트 전송 항목에서 제외합니다.
모델에는 종목·비중·공개 근거만 전달하고 수량·총자산·매입가는 제외합니다.
Ollama 기본 설정은 로컬 추론입니다. `LLM_BACKEND=openai`를 선택하면 모델 입력이 외부 API로 전송되고 별도 비용이 발생합니다.
OpenAI 사용 시 store=false를 적용하지만 모든 종류의 보관을 없앤다는 뜻은 아닙니다.
서버 임대비, 사이트 플랫폼 한도, 모델 API 요금은 사용하는 서비스의 조건에 따릅니다.
Yahoo Finance의 비공식 yfinance 조회는 지연·접근 제한·형식 변경이 있을 수 있습니다.

## 업로드된 코드에서 수정한 사항

- 토스 `result.items` 응답을 명세대로 파싱하고, 조회 실패를 잔고 0원으로 바꾸지 않습니다.
- 빈 WebSocket 함수를 실제 구독·재연결 구현으로 교체했습니다.
- USD/KRW 환율이 없으면 임의의 1,400원을 넣지 않고 계산을 중단합니다.
- KOSPI/KOSDAQ을 구분해 Yahoo 심볼을 매핑합니다.
- 모델 입력에 보유 수량을 그대로 전달하던 경로를 필드 허용 목록으로 제한했습니다.
- TLS 인증서 검증을 복구하고 certifi CA 번들을 사용합니다. 인증서 검증을 끄지 마세요.
- 계좌 원본 응답과 인증정보가 포함될 수 있는 예외 문자열 출력을 제거했습니다.
- 시연 시 latest_portfolio.json도 생성합니다.

## 검증 범위

보유 계산·근거 ID·거시 입력 독립성 등 로컬 모의 검증을 포함합니다.
실제 토스 인증, WebSocket 수신, Yahoo 라이브 조회, 실제 모델 호출, 장시간 운영과
사이트 외부 자동 연결은 본인 인증정보 및 실행 환경에서 추가 확인이 필요합니다.
사이트의 시연은 미리 작성한 결과이며 실제 AI 성능을 입증하지 않습니다.
