# 검증 기록

검증일: 2026-09-17 UTC

- 최신 첨부의 app.py, agents.py, broker.py, collectors.py, common.py 로직을 유지하고 FastAPI 연결 계층을 추가.
- 원본 사이트 UI 컴포넌트·CSS를 로컬 Vite 앱에 이식.
- 프론트엔드 TypeScript 검사 통과.
- 로컬용 및 공개용 프로덕션 빌드 통과.
- 오프라인 API 테스트 통과: 빈 데이터 처리, Python 가상 결과 연동, 부분 보고서 업로드, 공개 모드 API 거부, 외부 클라이언트·Host·Origin 거부, 임의 파일 차단, 잘못된 상태 파일·출처 URL 거부, 중복 작업 거부, 빌드 HTML·정적 자산·직접 경로 응답.
- 테스트에는 실제 계좌·토스 키·Ollama 추론을 사용하지 않음.
- 브라우저 도구의 로컬 주소 접근 제한으로 로컬 화면의 실제 클릭·시각 검증은 수행하지 못함. 원본의 반응형 CSS와 인터랙션 컴포넌트를 유지했고, 빌드·타입 검사·API/정적 자산 검증으로 확인한 범위를 구분함.

테스트 환경 주요 버전: Python 3.12, FastAPI 0.141.1, Pydantic 2.13.5, Uvicorn 0.53.0, React 19.2.6, Vite 8.0.13, TypeScript 5.9.3.

확인한 한계: 작업 상태는 서버 메모리에만 유지되므로 서버 재시작 후 복원되지 않음. 실제 24시간 운영·다중 사용자·원격 개인 API는 이 로컬 패키지의 제공 범위가 아님. app.py의 Mac/Linux 파일 잠금을 사용함.
